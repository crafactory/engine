# Crafactory Engine 交付说明

本次交付是一套可以运行、读写本地文件、并经过自动化测试的独立桌面笔记工作区，原创代码采用 MIT 许可。必须明确的是：**0.2.0 尚未完成你要求的“除订阅功能外，1:1 完全复刻 Obsidian”目标**，不能把这次交付当成最终验收通过。

## 仓库与实现

- **仓库**：[crafactory/engine](https://github.com/crafactory/engine)，代码已推送到 `main`。
- **Linux 安装包**：[v0.2.0 预发布下载页](https://github.com/crafactory/engine/releases/tag/v0.2.0)，包含未签名的 x64 AppImage、Debian 包及校验清单；[发布流程](https://github.com/crafactory/engine/actions/runs/38193971063)已在上传前验证打包程序。
- **技术结构**：Electron 桌面外壳、React 工作区、CodeMirror 6 编辑器、普通文件 Vault；没有远程账号或同步数据库。
- **资源**：Lucide 图标、本地打包的 Inter 字体，以及许可证兼容的 Markdown、图谱和 Canvas 库；保留第三方许可声明。
- **来源边界**：没有导入、反编译或改写 Obsidian 应用代码，也没有使用其品牌素材；实现依据是公开行为说明，不宣称正式法律意义上的双团队 clean-room 认证。

功能核对清单依据 [Obsidian 公开核心插件列表](https://help.obsidian.md/plugins)整理，另外记录了原生移动端、免费扩展及插件兼容等仍未实现的部分。Sync 和 Publish 是这次明确排除的订阅服务，其他尚未完成的功能并未被擅自算作“排除项”。

## 已有可运行的功能

- **文件与数据安全**：本地 Vault、新建/移动/重命名/回收站、自动保存、磁盘变化监听、写入冲突检测、历史版本恢复、中文路径与内容。
- **笔记编辑**：源码模式、Live 内联及顶层块预览、阅读模式、表格单元格编辑、任务勾选、撤销重做、查找替换、格式快捷键、链接与标签补全、部分斜杠命令。
- **笔记关联**：Wiki/Markdown 内部链接、别名、标题/块引用、反向链接、未链接提及、出站链接、大纲、标签、全局与局部图谱。
- **内容渲染**：任务勾选、表格、脚注、高亮、Callout 样式、数学公式、Mermaid 图、笔记和媒体嵌入。
- **可视化与属性**：JSON Canvas 卡片、移动/缩放/连接；基础 `.base` 表格、列表、卡片、过滤与属性编辑。
- **工作流**：快速切换、命令面板、多标签、一个分栏、保存工作区、书签、每日笔记、模板、随机/时间戳笔记、拆分与合并。
- **实用工具**：基础幻灯片、录音接口、受嵌入限制的网页查看器、导入附件、Markdown/HTML/PDF/ZIP 导出、简易 CLI。
- **扩展与设置**：亮暗主题、CSS 片段、可配置快捷键、核心功能开关，以及需要主动授权的独立 Worker 插件 API。

以上均为已实现的功能子集，不代表与参考软件的细节、设置、语法和边界行为完全相同。完整差距逐项写在仓库的 `docs/PARITY.md`，没有用一个未经证实的“完成百分比”代替验收。

## 启动

要求 Node.js 22.12 或更新版本，并有桌面图形环境。

```sh
git clone https://github.com/crafactory/engine.git
cd engine
npm ci
npm run desktop
```

首次启动使用 Documents 下的 `Crafactory Vault`，也可以在应用内打开已有文件夹。测试重要笔记前请先做独立备份，应用内快照并不能代替备份。

```sh
# 指定本地 Vault
npx electron . --vault /absolute/path/to/vault

# 只有临时示例数据的网页预览
npm run dev

# 在当前系统构建桌面包
npm run dist -- --publish never
```

网页预览使用内存数据，刷新会重置，不会获得你电脑的文件系统权限。实际持久化与本地目录操作由桌面程序完成；两者不是同一交付能力。
